We denote by :

\begin{itemize}
 \item $(\Sch, \pleft, \pmid, \pright)$ the graded tridendriform algebra on Schroeder tree;
 \item $\Sch(\nn)$ the set of Schroeder tree with $\nn$ leaves;
 \item $\SchF$ the set of forest of Schroeder tree.

\end{itemize}



\section{Levelled Schroeder Tree}

The set of levelled Shcroeder tree is denoted $\Schl$ while the levelled Schroeder trees with $n$ leaves if denoted $\Schl(\nn)$.
As to each levelled Schroeder tree corresponds a unique Schroeder tree we have a tirvial surjection
\begin{equation}
\pi_\nn:\Schl(\nn)\twoheadrightarrow\Sch(\nn)
\end{equation}
Maps $\pi_0$, $\pi_1$, $\pi_2$ and $\pi_3$ are bijectives while $\pi_\nn$ is not injective for $n\geq 4$.

\begin{defi}
Two levelled tree $t$ and $t'$ of $\Schl(\nn)$ are said \emph{equivalent}, denoted $t\equiv t'$, if it represents the same Schroeder tree, that is, $\pi_\nn(t)=\pi_\nn(t')$.
\end{defi}

For each $n\in \NN$ we want to construct a section of $\pi_n$.
