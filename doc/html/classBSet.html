Detailed Description

A class to represent subset of \(\{1,\ldots,32\}\) with a 32-bits encoding.

To each such set corresponds a unique integer between \(0\) and \(2^{32}-1\). The integer corresponding to the set \(S\) is given by \(\sum_{i\in S} 2^{i-1}\).
