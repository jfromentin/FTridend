This library is made to make computations in the free tridendriform Schroeder algebra.
It performs computations in this algebra using a grid representation of Schroeder trees and explicit expressions of the tridendriform products.
See "EFFECTIVE APPROACH OF THE TRIDENDRIFORM SCHROEDER TREE ALGEBRA" (https://arxiv.org/pdf/2603.29393) for more mathematical details.
