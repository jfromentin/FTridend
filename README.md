This library is made to make computations in the free tridendriform Schroeder algebra.
It performs computations in this algebra using a grid representation of Schroeder trees and explicit expressions of the tridendriform products.
See "EFFECTIVE APPROACH OF THE TRIDENDRIFORM SCHROEDER TREE ALGEBRA" (https://arxiv.org/pdf/2603.29393) for more mathematical details.

Installation guide of FTridend (last update 03/11/2026): 
-clone the repository on GitHub;
-open a terminal (bash for Linux)
-place you in the folder containing the repository FTridend
-place yourself in the repository FTridend
-execute the "make" command to produce two executable files ftridend and ftridend_test
-open a jupyter environment in this folder and type "import FTridend". The library is now available.
